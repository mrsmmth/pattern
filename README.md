# pattern

自作バッキングを「名前」ではなく4拍の形で探す、ローカルMIDIライブラリです。

- `.mid` / `.midi` をドロップすると即保存
- 一覧は先頭4拍を自動でピアノロール化
- カードタップで4拍プレビュー
- お気に入り / 使用回数 / 追加順で並び替え
- `COPY` はブラウザのMIDIクリップボード書き込みを試し、非対応なら `.mid` 書き出しへ自動フォールバック
- カードから外部アプリへのMIDIドラッグアウトも対応ブラウザでは試行可能
- データはIndexedDBに端末内保存
- PWA / オフライン対応

GitHub Pagesなどの静的ホスティングに、このフォルダをそのまま配置して使えます。
