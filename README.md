# pattern

自作バッキングを「名前」ではなく4拍の形で探す、ローカルMIDIライブラリです。

- `.mid` / `.midi` をドロップすると即保存
- 一覧は「最初にノートがある位置」から4拍だけを自動でピアノロール化
- カードタップで4拍プレビュー
- お気に入り / 使用回数 / 追加順で並び替え
- `DRAG → LOGIC` を主操作にして外部アプリへのMIDIドラッグアウトを試行
- ↓ボタンから `.mid` 書き出しも可能
- データはIndexedDBに端末内保存
- PWA / オフライン対応
- アプリ全体は1画面固定。パターンが増えたら棚だけスクロール

GitHub Pagesなどの静的ホスティングに、このフォルダをそのまま配置して使えます。
